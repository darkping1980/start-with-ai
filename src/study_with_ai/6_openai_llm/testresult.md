한 줄 요약

자바(Java)는 한 번 작성한 프로그램을 여러 운영체제에서 실행할 수 있도록 만든 대표적인 프로그래밍 언어입니다.

기술이 무엇인지

자바는 프로그램을 만들 때 사용하는 프로그래밍 언어입니다. 웹사이트의 서버, 안드로이드 앱, 기업용 시스템, 금융 프로그램 등 다양한 분야에서 사용됩니다.

자바의 가장 큰 특징은 “한 번 작성하고 여러 곳에서 실행한다”는 개념입니다. 자바로 작성한 프로그램은 자바 가상 머신이라는 실행 환경을 통해 윈도우, macOS, 리눅스 등 여러 운영체제에서 실행할 수 있습니다.

자바 가상 머신은 JVM이라고 부릅니다. JVM은 자바 프로그램을 운영체제에 맞게 실행해 주는 중간 실행 프로그램입니다.

왜 필요한지

컴퓨터마다 사용하는 운영체제와 내부 구조가 다릅니다. 일반적인 프로그램은 윈도우용, macOS용, 리눅스용으로 따로 만들어야 할 수 있습니다.

자바는 프로그램을 바로 운영체제에서 실행하지 않고, 먼저 바이트코드라는 중간 형태로 변환합니다. JVM이 이 바이트코드를 읽어 각 운영체제에서 실행합니다.

따라서 개발자는 운영체제별로 프로그램을 완전히 새로 만들 필요가 줄어듭니다. 특히 여러 종류의 컴퓨터에서 동작해야 하는 서버와 기업 시스템을 만들 때 유용합니다.

어떻게 동작하는지

자바 프로그램이 실행되는 과정은 다음과 같습니다.

첫째, 개발자가 자바 소스 코드를 작성합니다. 소스 코드는 사람이 읽고 작성하는 프로그램 코드입니다.

둘째, 자바 컴파일러가 소스 코드를 바이트코드로 변환합니다. 컴파일러는 사람이 작성한 코드를 컴퓨터가 실행할 수 있는 형태로 바꾸는 프로그램입니다.

셋째, JVM이 바이트코드를 읽고 실제 컴퓨터에서 실행합니다.

예를 들어 다음은 화면에 문장을 출력하는 간단한 자바 프로그램입니다.

public class Hello {
    public static void main(String[] args) {
        System.out.println("안녕하세요, 자바!");
    }
}

이 프로그램을 실행하면 다음과 같은 결과가 나옵니다.

안녕하세요, 자바!

public class Hello는 Hello라는 이름의 클래스를 만든다는 뜻입니다. 클래스는 데이터와 기능을 하나로 묶어 놓은 설계도라고 생각하면 됩니다.

main 메서드는 프로그램이 시작되는 특별한 기능입니다. 메서드는 특정 작업을 수행하는 코드 묶음입니다.

System.out.println은 화면에 글자를 출력하는 기능입니다.

어디에 사용하는지

자바는 다음과 같은 곳에서 많이 사용됩니다.

웹사이트 서버 개발에 사용됩니다. 예를 들어 회원 가입, 로그인, 결제, 주문 처리 같은 기능을 구현할 수 있습니다.

기업용 프로그램 개발에 사용됩니다. 은행, 보험사, 공공기관처럼 안정성과 유지 관리가 중요한 시스템에서 자주 사용됩니다.

안드로이드 앱 개발에 사용되었습니다. 현재는 코틀린이라는 언어도 많이 사용하지만, 기존 안드로이드 앱에는 자바로 작성된 코드가 많이 남아 있습니다.

데스크톱 프로그램 개발에도 사용할 수 있습니다.

빅데이터와 데이터 처리 시스템에서도 사용됩니다. 하둡과 같은 일부 대규모 데이터 처리 기술이 자바 생태계와 관련이 있습니다.

게임 서버와 실시간 서비스의 서버 개발에도 사용할 수 있습니다.

장점과 단점

자바의 장점은 다음과 같습니다.

여러 운영체제에서 실행하기 쉽습니다. JVM이 운영체제의 차이를 어느 정도 처리해 줍니다.

많은 개발자가 사용하므로 참고할 자료와 학습 자료가 많습니다.

스프링과 같은 강력한 개발 도구와 라이브러리가 많습니다. 라이브러리는 다른 개발자가 미리 만들어 놓은 기능 모음입니다.

프로그램의 구조를 체계적으로 만들기 좋습니다. 규모가 큰 프로젝트를 여러 개발자가 함께 관리하기에 적합합니다.

자동 메모리 관리 기능이 있습니다. 가비지 컬렉션이라는 기능이 더 이상 사용하지 않는 메모리를 자동으로 정리합니다.

오랫동안 사용된 언어라서 기업용 시스템과 안정적인 기술이 많이 쌓여 있습니다.

단점도 있습니다.

간단한 프로그램을 만들 때도 작성해야 하는 코드가 비교적 많을 수 있습니다.

C나 C++처럼 컴퓨터에 매우 가까운 언어보다 실행 속도가 느릴 수 있습니다. 다만 일반적인 웹 서버나 업무 프로그램에서는 충분히 빠른 경우가 많습니다.

JVM을 실행해야 하므로 프로그램이 메모리를 비교적 많이 사용할 수 있습니다.

자바의 문법과 객체지향 개념을 처음 배우는 초보자에게는 다소 어렵게 느껴질 수 있습니다.

실제 사용 예시

온라인 쇼핑몰을 자바로 만든다고 가정해 보겠습니다.

사용자가 로그인하면 자바 서버가 아이디와 비밀번호를 확인합니다.

상품을 검색하면 자바 서버가 데이터베이스에서 상품 정보를 가져옵니다.

장바구니에 상품을 담으면 자바 서버가 사용자의 장바구니 정보를 저장합니다.

결제하면 자바 서버가 주문 정보를 저장하고 결제 시스템과 연결합니다.

이때 자바만 사용하는 것은 아닙니다. 화면은 HTML, CSS, 자바스크립트로 만들고, 서버는 자바와 스프링으로 만들며, 데이터는 MySQL이나 PostgreSQL 같은 데이터베이스에 저장할 수 있습니다.

관련 기술

JVM은 자바 프로그램을 실행하는 환경입니다.

JDK는 자바 개발 키트입니다. 자바 프로그램을 개발할 때 필요한 컴파일러와 실행 도구가 포함되어 있습니다.

JRE는 자바 실행 환경입니다. 자바 프로그램을 실행하는 데 필요한 구성 요소를 포함합니다. 다만 최근 자바 배포판에서는 JDK를 중심으로 사용하는 경우가 많습니다.

스프링은 자바로 웹 서버와 기업용 애플리케이션을 만들 때 많이 사용하는 개발 프레임워크입니다. 프레임워크는 프로그램의 기본 구조와 자주 쓰는 기능을 제공하는 도구입니다.

스프링 부트는 스프링을 더 쉽게 시작하고 설정할 수 있도록 만든 기술입니다.

메이븐과 그래들은 자바 프로젝트의 라이브러리 설치와 빌드를 관리하는 도구입니다. 빌드는 소스 코드를 실행 가능한 프로그램으로 만드는 과정입니다.

자바스크립트는 이름에 자바가 들어가지만 자바와는 다른 언어입니다. 웹 브라우저에서 화면을 움직이게 하거나 서버 프로그램을 만드는 데 사용됩니다.

관련 기술과의 차이점 또는 관계

자바와 자바스크립트는 이름이 비슷하지만 서로 다른 언어입니다. 자바는 서버와 기업용 프로그램에 많이 사용되고, 자바스크립트는 웹페이지의 동작과 웹 서버 개발에 많이 사용됩니다.

자바와 파이썬은 모두 배우기 좋은 고급 프로그래밍 언어입니다. 파이썬은 문법이 간단해서 학습과 데이터 분석에 많이 사용됩니다. 자바는 코드가 더 엄격하고 구조적인 편이라 대규모 기업 시스템 개발에 강점이 있습니다.

자바와 C++는 모두 객체지향 프로그래밍을 지원합니다. 객체지향 프로그래밍은 프로그램을 여러 객체라는 단위로 나누어 만드는 방식입니다. C++는 컴퓨터 자원을 세밀하게 제어할 수 있지만, 자바는 메모리 관리가 더 편리한 편입니다.

자바와 코틀린은 모두 JVM에서 실행될 수 있습니다. 코틀린은 자바보다 간결한 문법을 제공하며, 현재 안드로이드 앱 개발에서 많이 사용됩니다. 자바와 코틀린은 같은 프로젝트에서 함께 사용할 수도 있습니다.

초보자가 기억하면 좋은 핵심 내용

자바는 프로그램을 만드는 언어입니다.

자바 프로그램은 보통 JVM 위에서 실행됩니다.

자바의 핵심 장점은 여러 운영체제에서 실행하기 쉽다는 점입니다.

자바는 웹 서버, 기업용 시스템, 안드로이드 앱, 데이터 처리 시스템 등에 사용됩니다.

JDK는 자바를 개발할 때 필요하고, JVM은 자바 프로그램을 실행할 때 중심 역할을 합니다.

자바스크립트는 자바와 다른 언어입니다.

처음 배울 때는 변수, 자료형, 조건문, 반복문, 메서드, 클래스, 객체 순서로 공부하면 좋습니다.

자바는 단순히 문법만 배우는 것보다 객체지향 프로그래밍의 기본 개념과 함께 공부하면 더 잘 이해할 수 있습니다.
