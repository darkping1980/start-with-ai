LEGB 스코프: 이름은 어디서 찾을까?

스코프
파이썬은 이름을 찾을 때 보통 Local → Enclosing → Global → Built-in 순서로 탐색합니다.
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)
    inner()
기억: 함수 안에서 이름을 찾다가 없으면 바깥 함수, 모듈 전역, 마지막으로 내장 이름까지 올라갑니다.

Iterable → Iterator → next()

이터레이터
for문이 내부적으로 어떻게 하나씩 값을 꺼내는지 이해하는 핵심 구조입니다.

it = iter(nums)

print(next(it))  # 10

데코레이터는 함수를 감싸는 함수

데코레이터
기존 함수 코드를 직접 고치지 않고 앞뒤 동작을 덧붙이는 파이썬의 대표 패턴입니다.
def log_call(func):
    def wrapper():
        print("호출 전")
        func()
        print("호출 후")
    return wrapper

@log_call
def hello():
    print("hello")
@log_call은 대략 hello = log_call(hello)와 같은 의미입니다.

nonlocal 키워드

스코프
중첩 함수에서 바깥 함수의 지역 변수를 바꾸고 싶을 때 사용합니다.
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

c = counter()
print(c())
print(c())
클로저 상태를 갱신할 때 등장합니다.
파이썬 중급

generator 함수와 yield

제너레이터
yield를 사용하면 값을 한 번에 모두 만들지 않고 필요할 때 하나씩 생성합니다.
def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for n in count_up_to(3):
    print(n)
return은 함수 종료, yield는 상태를 기억한 채 잠시 멈춥니다.

리스트 vs 제너레이터

yield from

제너레이터
다른 iterable의 값을 대신 하나씩 yield할 때 코드를 간단하게 만듭니다.
def flatten(groups):
    for group in groups:
        yield from group

print(list(flatten([[1, 2], [3, 4]])))

            return result
        return wrapper
    return decorator

asyncio.gather
