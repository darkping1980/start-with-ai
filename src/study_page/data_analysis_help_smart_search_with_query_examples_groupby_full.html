Plotly 불러오기 — px / go

px = Plotly Express, 고수준·간단한 API

px와 go 차이 한눈에 보기

Plotly 개념
둘은 별개의 그래프 엔진이 아닙니다. px로 만든 그래프도 결국 go.Figure 객체입니다.

go → 여러 trace 조합 · layout 세밀 조정 · 복잡한 그래프에 유리
추천 → 처음엔 px로 만들고, 필요하면 fig.update_layout() 등으로 세부 조정
fig = px.scatter(df, x="공부시간", y="시험점수")

특정 컬럼만 조회한 뒤 복사본 만들기

전체 DataFrame에서 필요한 컬럼만 골라 새 DataFrame으로 만들고 싶을 때
df_copy = df[["이름", "국어", "영어"]].copy()
1. df → 전체 데이터
2. [["이름", "국어", "영어"]] → 필요한 컬럼만 선택
3. copy() → 선택한 결과를 별도 복사
4. df_copy → 새 DataFrame으로 저장
원본 df는 그대로 두고, 필요한 컬럼만 따로 작업할 수 있습니다.

조건에 맞는 데이터만 조회한 뒤 복사하기

예: 국어 80점 이상인 학생만 따로 작업하고 싶을 때
df_copy = df[df["국어"] >= 80].copy()

df["국어"] >= 80 → 국어 80점 이상 조건
df[조건] → 조건에 맞는 행만 조회
.copy() → 조회 결과를 새 DataFrame으로 복사

조건 조회 + 필요한 컬럼만 선택 + 복사

조건에 맞는 행 중 필요한 열만 뽑아서 새 DataFrame으로 만들고 싶을 때

    df["국어"] >= 80,
    ["이름", "국어", "영어"]

② 이름·국어·영어 컬럼만 선택

이상치 확인 → 제거 전후 상관계수 비교

이상치가 상관계수에 얼마나 영향을 주는지 비교하는 학습용 예제입니다.
x = "공부시간"
y = "시험점수"

before = df[x].corr(df[y])

q1 = df[y].quantile(0.25)
q3 = df[y].quantile(0.75)
iqr = q3 - q1
low = q1 - 1.5 * iqr
high = q3 + 1.5 * iqr

clean = df[df[y].between(low, high)].copy()
after = clean[x].corr(clean[y])

print("이상치 처리 전:", before)
print("이상치 처리 후:", after)
이상치는 이유 없이 삭제하면 안 됩니다. 실제 오류인지, 중요한 극단 사례인지 데이터 의미를 먼저 확인하세요.
